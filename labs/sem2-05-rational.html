Divide by Almost Zero

The asymptote is not extra decoration. It appears because the denominator is heading toward zero.

The idea

A rational function is one polynomial divided by another. This one is y = (x + 1) ÷ (x − 2).

At x = 2 the denominator is zero, so the function has no finite value. Close to 2, dividing by a tiny negative or positive number makes the curve plunge or climb. That is the vertical asymptote.

Far away, the +1 and −2 matter less compared with x. The fraction gets closer to x ÷ x = 1. That is the horizontal asymptote.

The plotter lifts its pen at the non-finite value instead of joining the two branches through a place the function never reaches.

Challenges

  1. Change vertical = 2 to vertical = -3. The zero denominator and the vertical asymptote move together.
  2. Change numeratorShift to -2. The numerator and denominator are now both x − 2. Everywhere except x = 2 the value is 1; at x = 2 there is still a hole.
  3. Set numeratorShift = 0 and vertical = 0. The expression is x ÷ x: still undefined at zero, still 1 everywhere else.
  4. Change the numerator to 2 * x + numeratorShift. Check values at x = 100 and x = −100. Which horizontal value does the curve now approach?
  5. Move the two marked test points closer: use vertical - 0.1 and vertical + 0.1. Watch how quickly their y values grow.
If you know Python

The formula and / division are identical in JavaScript and Python.

At exactly zero, JavaScript number division gives Infinity here. Python raises ZeroDivisionError. Both are telling you the same algebraic fact: x = 2 is not in the domain.
