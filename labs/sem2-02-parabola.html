Bend the Parabola

Three numbers, one curve. The formula for the roots is in the code, so you can watch it agree with the picture.

The idea

A quadratic function is y = ax² + bx + c.

The roots are the x values where y is 0 — where the curve crosses the x axis.

x = (−b ± √(b² − 4ac)) ÷ 2a

discriminant = b² − 4ac

vertex x = −b ÷ 2a

The discriminant is the part under the square root. Positive means two roots, zero means one, negative means the curve never reaches the axis and there is no real root.

The code computes all of that and marks it. Change a, b or c and the marks move with the curve.

Challenges

  1. Change a to -1. The parabola opens downward and the vertex becomes the highest point instead of the lowest.
  2. Change a to 0.25, then 4. Same roots? Find out. a controls how tightly the curve is squeezed.
  3. Set c = 5 with a = 1, b = -2. The discriminant goes negative, the curve floats above the axis, and the code says so instead of drawing a root that does not exist.
  4. Find a set of numbers where the discriminant is exactly 0. Try a = 1, b = -2, c = 1. One root, sitting exactly under the vertex — that is not a coincidence, and the two formulas show why.
  5. Add say("y at the vertex:", q(vertexX)); at the end. For a positive a, no x you can pick will beat it.
  6. Swap the exponent: change x ** 2 to x ** 3 and run. It is not a parabola any more — that is what makes the squared term the definition of quadratic.
Why JavaScript and not Python

Python in the browser needs a ten-megabyte runtime downloaded before anything draws. This page has no downloads and no network at all, so it opens the same on a slow connection or none.

x ** 2 is the same in JavaScript and Python. JS also has Math.pow(x, 2), which is the older spelling.

Math.sqrt(d) is Python's math.sqrt(d).

if (disc > 0) { ... } else if (disc === 0) { ... } is Python's if / elif. JS uses === for "equal" because == quietly converts types first, and that is a real source of bugs.
