Move the Line

Two numbers decide everything a line does. Change one, run it, watch.

The idea

A linear function is y = mx + b.

m is the slope: how much y changes for one step right in x.

b is the intercept: the value of y when x is 0.

The code below draws that function. It already works — press Run, then start changing numbers.

Challenges

  1. Change m to -1 and run. Which way does the line tilt now?
  2. Set m = 0. What kind of function is left, and what is its range?
  3. Leave m alone and change b to 4. The line does not tilt — it slides. That is the whole difference between the two numbers.
  4. Try m = 0.5. Slope does not have to be a whole number.
  5. Add a second line. Write function steep(x) { return 8 * x; } under the first function, then add g.plot(steep, "O = 8N"); before the say lines. That is the Nether portal rule from the mini-lesson, drawn next to yours.
  6. Make the code find the slope instead of being told it. Add say("slope from two points:", (line(5) - line(1)) / (5 - 1)); and check it equals m. That fraction is rise over run.
Why JavaScript and not Python

Python in a browser means downloading about ten megabytes before anything happens, every time. JavaScript is already here, so the picture appears instantly and works offline. The algebra is identical; only the punctuation moves.

Three differences worth carrying back to Python:

let m = 2; in JS is just m = 2 in Python — JS wants you to declare a name the first time.

function line(x) { return m * x + b; } is def line(x): return m * x + b — braces instead of a colon and indentation, and return is required in both.

2 ** 3 means the same thing in both languages. Math.pow(2, 3) is the older JS way and still common.
