Where the Root Begins

A square-root curve has a real starting point. The code tries the forbidden side and shows exactly what happens.

The idea

The parent radical function is y = √x. It starts at x = 0 because no real number squares to make a negative number.

This one is y = √(x − start) + up. start slides the beginning sideways; up slides it vertically.

The domain is not a rule pasted on afterward. The code actually tests x < start and returns NaN, so the plotter has no real point to draw there.

Challenges

  1. Change start to -3. The curve begins three units left of the y axis, and the domain moves with it.
  2. Set up = 2. The starting x stays put while every y value rises four units from the starter picture.
  3. Change Math.sqrt(x - start) to 2 * Math.sqrt(x - start). The curve stretches upward without changing its domain.
  4. Remove the if check and run. JavaScript's own square root still returns NaN for a negative input. The check makes the reason readable; it does not invent the restriction.
  5. Change the graph window to graph(-2, 30, -5, 5). The curve keeps rising, but more slowly and slowly.
If you know Python

JavaScript uses Math.sqrt(value). Python uses math.sqrt(value) after import math.

There is one useful difference: JavaScript returns NaN for Math.sqrt(-1), while Python raises an exception. Either way, there is no real y value to plot.
