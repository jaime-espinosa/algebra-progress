Where Two Lines Cross

Solve the system with algebra, then let the picture check your answer.

The idea

A system of two linear equations asks: which pair (x, y) works in both at once?

On a graph that is the point where the lines cross.

In algebra you set the two right-hand sides equal:

m₁x + b₁ = m₂x + b₂

x(m₁ − m₂) = b₂ − b₁

x = (b₂ − b₁) ÷ (m₁ − m₂)

The code does exactly that, then marks the point it found. If the mark sits on the crossing, the algebra was right.

Challenges

  1. Change b2 to 5 and run. The crossing moves; the code finds it anyway.
  2. Set m2 = 2, the same slope as line A. Read what the output says about x. Parallel lines never meet, and the division by m1 - m2 divides by zero — the algebra tells you "no solution" in exactly the same breath as the picture does.
  3. Now also set b2 = -3. Both lines are identical, x comes out as NaN (0 ÷ 0), and every point on the line is a solution. Three outcomes, one formula.
  4. Put the lines back to m1 = 2, b1 = -3, m2 = -1, b2 = 3 and change the last say to check line A instead: say("check in line A:", lineA(x));
  5. Solve one by hand first. Pick m1 = 3, b1 = 1, m2 = 1, b2 = 7, work out x on paper, then run it and see whether you agree with the machine.
Why JavaScript and not Python

Running Python in a browser means a ten-megabyte download before the first line executes. JavaScript is already loaded, so this page is instant and works with no connection at all.

let m1 = 2, b1 = -3; declares two names at once. Python writes m1, b1 = 2, -3.

JS const means the name cannot be pointed at something else later. Python has no direct equivalent.

Division is / in both, but JS 6 / 4 gives 1.5 where Python 3 also gives 1.5 — it is Python's // that throws the fraction away.
