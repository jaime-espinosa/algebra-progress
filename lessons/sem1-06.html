Piecewise Functions and Absolute Value

Coordinates already contain this algebra.

The Minecraft structure

Spawn sits at a coordinate.

You can travel east or west.

Distance ignores the direction.

Teleport from x = 0 to x = −120.

Your x-distance is |−120| = 120 blocks.

Along the x-axis, that distance uses absolute value.

Biome rules can change across coordinate boundaries.

A redstone conditional chooses the matching branch.

The algebra

|x| = −x when x < 0

|x| = x when x ≥ 0

Absolute value measures distance from zero.

Its domain is all real numbers.

Its range is [0, ∞).

A piecewise function uses rules on defined domains.

Each input must select exactly one rule.

The valley graph

Both sides are straight rays.

This V is not a parabola.

Worked example

Your valley floor follows y = |x|.

At x = −4, use the negative branch.

y = −(−4) = 4

At x = 0, use the included branch.

y = 0

The boundary belongs only to x ≥ 0.

So every coordinate gets one height.
