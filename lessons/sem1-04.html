S1 // SECTION 04 // INPUT AND OUTPUT

Introduction to Functions

A furnace gives each accepted input one predictable output.

The Minecraft structure

A furnace is a function.

Put raw iron in, and an iron ingot comes out every time.

The input set contains what the furnace accepts.

The output set contains what the furnace can produce.

Raw iron and an iron sword can both smelt to an iron ingot.

Two inputs sharing one output still make a function.

A function forbids one input from giving two different outputs.

Ore drops are not a function of the ore block alone.

Fortune III can give the same block different drop counts.

A hidden random roll is another input needed to make that rule a function.

The algebra

f: D → R

x → f(x)

Each x ∈ D has exactly one output f(x).

A function assigns every allowed input exactly one output.

Read f(x) as the rule f applied to x.

The domain is the set of allowed inputs.

The range is the set of outputs actually produced.

A graph is a function when every vertical line hits it at most once.

This check is the vertical line test.

The furnace mapping

Each input square has one arrow.

Both arrows may end at the same output.

Worked example

Define f(x) = 8x as the items smelted from x pieces of coal.

Evaluate the rule at zero pieces of coal.

f(0) = 8(0)

f(0) = 0

Evaluate the rule at three pieces of coal.

f(3) = 8(3)

f(3) = 24

Evaluate the rule at twelve pieces of coal.

f(12) = 8(12)

f(12) = 96

Now solve f(x) = 64.

f(x) = 64

8x = 64

x = 64 ÷ 8

x = 8

f(8) = 8(8) = 64

The domain here is the whole numbers {0, 1, 2, ...}.

The range is the multiples of 8, {0, 8, 16, ...}.
