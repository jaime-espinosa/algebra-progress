S1 // SECTION 05 // CONSTANT RATE

Linear Functions

A Nether shortcut turns one block into eight.

The Minecraft structure

Nether portals connect coordinates between dimensions.

One Nether block corresponds to eight Overworld blocks on the horizontal axes.

Every extra Nether block buys exactly eight more Overworld blocks.

That constant rate of change makes the coordinate rule linear.

The ratio applies only to the x and z axes.

The y coordinate is not scaled and maps 1:1.

The portal rule has slope 8 on two axes and slope 1 on the height axis.

The algebra

y = mx + b

m = rise ÷ run = change in y ÷ change in x

The slope m is the constant rate of change.

The intercept b is the value of y when x = 0.

A proportional function has b = 0 and passes through the origin.

A general linear function can have b ≠ 0.

The domain of a linear function is all real numbers.

When m ≠ 0, the range is all real numbers.

When m = 0, the range is the single value {b}.

The portal line

The axes use different visual scales.

Each plotted pair still satisfies O = 8N.

Worked example

You stand in the Nether at x = −125 and z = 40.

Multiply each horizontal coordinate by 8.

x = 8 × (−125)

x = −1000

z = 8 × 40

z = 320

The matching Overworld coordinates are x = −1000 and z = 320.

Now place a Nether hub for an Overworld base at x = 2400.

Nether x = Overworld x ÷ 8

Nether x = 2400 ÷ 8

Nether x = 300

The points (0, 0) and (300, 2400) reveal the same rate.

m = (2400 − 0) ÷ (300 − 0)

m = 2400 ÷ 300

m = 8
