S2 // SECTION 02 // THE ARC

Quadratic Functions

A fired arrow traces a rise, a peak, and a fall.

The Minecraft structure

An arrow leaves the bow and rises.

It slows, turns over, and falls faster and faster.

That arc has the shape of a parabola.

The highest point is the vertex.

Aiming above a distant target compensates for the downward curve.

Minecraft applies gravity and air drag once per tick.

The real path is a discrete stepped approximation, not an exact parabola.

Drag makes the descent shallower than a true parabola predicts.

A quadratic is a useful model, not the literal engine behavior.

The algebra

f(x) = ax² + bx + c, where a ≠ 0

f(x) = a(x − h)² + k

axis of symmetry: x = −b ÷ (2a)

vertex: (h, k)

The domain is all real numbers.

When a < 0, the parabola opens downward.

For a < 0, the range is (−∞, k].

When a > 0, the parabola opens upward.

For a > 0, the range is [k, ∞).

The arrow arc

The guide line divides the curve into matching halves.

Equal times from t = 2 have equal modeled heights.

Worked example

Model the arrow height in blocks after t seconds.

h(t) = −5t² + 20t + 2

Find the axis of symmetry first.

t = −20 ÷ (2 × −5)

t = −20 ÷ −10

t = 2

Substitute t = 2 to find the peak height.

h(2) = −5(2²) + 20(2) + 2

h(2) = −5(4) + 40 + 2

h(2) = −20 + 40 + 2

h(2) = 22 blocks

Check equal times on opposite sides of t = 2.

h(1) = −5 + 20 + 2 = 17

h(3) = −45 + 60 + 2 = 17

The equal heights confirm the symmetry.

The modeled range is (−∞, 22].
