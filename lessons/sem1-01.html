Algebra Basics

A crafting recipe turns a count into an expression.

The Minecraft structure

One log crafts into four planks.

One chest costs eight planks.

A variable is the unknown count you have not mined yet.

The recipe P = 4L converts L logs into P planks.

Multiply then add because the recipe tree converts logs before totaling planks.

Crafting is not reversible because planks cannot be uncrafted into a log.

An algebraic equation can still be read in either direction.

The algebra

P = 4L

3x + 2x = 5x

4L + 8

Evaluating means substituting a value and calculating the result.

Like terms have the same variable part and can be combined.

Multiplication happens before addition in 4L + 8.

The algebraic expression 4L is defined for every real value of L.

As the function P = 4L, its domain is ℝ and its range is ℝ.

In this crafting model, L has domain {0, 1, 2, …}.

Its practical range for P is {0, 4, 8, 12, …}.

The real-number expression and the whole-number model are different claims.

The plank chart

Each additional log adds four planks.

Only whole-number log counts appear in this chart.

Worked example

You want three chests.

Each chest costs eight planks.

Planks needed = 3 × 8

Planks needed = 24

Now solve for the logs that craft those planks.

4L = 24

L = 24 ÷ 4

L = 6

Then add one crafting table that costs four planks.

Total planks = 24 + 4

Total planks = 28

4L = 28

L = 28 ÷ 4

L = 7

Six logs cover the chests.

Seven logs cover the chests and crafting table.
