Exponential Functions

Multiplication changes the growth pattern.

The Minecraft structure

A doubling farm multiplies every cycle.

One output becomes two, then four.

Ideal villager breeding can follow the same pattern.

Real villagers need beds, food, cooldowns, and time.

Those limits eventually break the simple model.

Java XP costs also grow with level.

Their ratios are not constant.

So level costs are not exponential.

The algebra

f(x) = a · bˣ

a ≠ 0

b > 0 and b ≠ 1

The variable appears in the exponent.

The domain is all real numbers.

For a > 0, the range is (0, ∞).

For a < 0, the range is (−∞, 0).

Growth uses b > 1.

Decay uses 0 < b < 1.

The doubling curve

Equal cycles create equal ratios.

The graph is not a parabola.

Worked example

Your scripted farm starts with six entities.

Each cycle creates one copy per entity.

The population doubles each completed cycle.

N(n) = 6 · 2ⁿ

N(4) = 6 · 2⁴

N(4) = 96 entities

Here, n counts completed cycles.

Its domain is {0, 1, 2, …}.

Its range is {6 · 2ⁿ | n ∈ ℤ≥0}.

Constant differences suggest linear growth.

Constant ratios identify exponential growth.

Quadratics have constant second differences instead.
