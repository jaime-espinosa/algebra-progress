Systems of Equations and Inequalities

Two timed runs can reveal two hidden farm rates.

The Minecraft structure

Two mob farms feed one collection hopper.

The chest shows the combined total but hides each farm's share.

One timed run gives one equation about both rates.

A different timed run gives a second equation.

Two independent equations can recover both individual rates.

This model only works when each farm's rate is genuinely constant.

Real spawn rates drift with chunk loading, mob caps, and light level.

The constant-rate model is only an approximation.

The algebra

A₁x + B₁y = C₁

A₂x + B₂y = C₂

Substitution replaces one variable with an equal expression.

Elimination adds or subtracts equations to cancel a variable.

Crossing lines give one solution.

Parallel lines give no solution.

The same line gives infinitely many solutions.

A linear inequality system has a solution region, not one point.

An equation you can write as y = mx + b graphs a line whose domain is all real numbers.

A vertical line such as 2x = 6 is still a line, but x is fixed and y is free.

The solution is the ordered pair lying on both lines at once.

The crossing lines

The crossing point satisfies both equations.

Its coordinates are the two farm rates.

Worked example

Let a be farm A's rate in items per minute.

Let b be farm B's rate in items per minute.

Run 1 uses both farms for 5 minutes and produces 40 items.

5a + 5b = 40

a + b = 8

Run 2 uses farm A for 8 minutes and farm B for 3 minutes.

Together they produce 49 items.

8a + 3b = 49

Solve the first equation for b and substitute it into the second.

b = 8 − a

8a + 3(8 − a) = 49

8a + 24 − 3a = 49

5a + 24 = 49

5a = 25

a = 5

b = 8 − 5

b = 3

Substitute both rates back into both original equations.

5(5) + 5(3) = 25 + 15 = 40

8(5) + 3(3) = 40 + 9 = 49

Both checks match the recorded totals.
