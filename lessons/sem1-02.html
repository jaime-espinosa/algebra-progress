Linear Equations and Inequalities

Furnace fuel turns a target into a boundary.

The Minecraft structure

One piece of coal smelts eight items.

A pile of raw iron sets the number of items to smelt.

An equation finds the exact coal count for a full batch.

An inequality allows more coal than the minimum but never less.

Coal comes in whole pieces.

The algebra can give a fraction, but the practical answer must round up.

The algebra

ax = b → x = b ÷ a

ax + c = b

ax = b − c

x = (b − c) ÷ a

a ≠ 0

Inverse operations undo addition and multiplication.

The function f(x) = ax + c has domain ℝ and range ℝ when a ≠ 0.

A linear equation with a nonzero coefficient has exactly one real solution.

Its solution set is the single value {(b − c) ÷ a}.

A linear inequality has an interval of real solutions.

Multiplying or dividing both sides by a negative flips the inequality sign.

For example, −2x ≥ 6 becomes x ≤ −3.

The coal boundary

The filled point includes thirteen.

The ray includes every greater value.

Worked example

First, smelt ninety-six raw iron.

Each coal smelts eight items.

8c = 96

c = 96 ÷ 8

c = 12 coal

Next, smelt one hundred raw iron.

You need enough fuel for at least one hundred items.

8c ≥ 100

c ≥ 100 ÷ 8

c ≥ 12.5

The algebraic solution is the real interval [12.5, ∞).

The practical domain is whole pieces of coal.

Round up from 12.5 and bring 13 coal.

8 × 13 = 104

104 ≥ 100
