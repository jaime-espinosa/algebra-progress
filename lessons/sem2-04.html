S2 // SECTION 04 // DISTANCE

Radical Functions

A square root turns coordinate changes into straight-line distance.

The Minecraft structure

The F3 screen gives your x, y, and z coordinates.

Moving from a base to a stronghold marker changes x and z.

Square the two horizontal differences, add them, and take the square root.

That square root is a radical function.

The principal square root never returns a negative distance.

Straight-line distance is almost never the distance you actually walk.

Terrain, water, and changes in y make the real travel distance longer.

A three-dimensional distance also includes the y difference.

The two-coordinate version only measures how far across the map.

The algebra

f(x) = √x

d = √((x₂ − x₁)² + (z₂ − z₁)²)

√72 = √(36 · 2) = 6√2

The domain of f(x) = √x is [0, ∞).

The range of f(x) = √x is [0, ∞).

The principal square root is defined only for non-negative inputs.

It never returns a negative value.

The expression under the distance radical is a sum of squares.

A sum of squares cannot be negative, so the distance is always defined.

Simplify a radical by removing perfect-square factors.

Squaring both sides can introduce extraneous solutions.

Check every proposed solution in the original radical equation.

Distance triangle

The legs use one scale, so 156² + 65² = 169².

The hypotenuse is the horizontal map distance.

Worked example

Your base is at x = 120, z = −45.

The stronghold marker is at x = −36, z = 20.

Δx = 120 − (−36)

Δx = 120 + 36

Δx = 156

Δz = −45 − 20

Δz = −65

(−65)² = 65²

Square each difference before adding.

d = √((120 − (−36))² + (−45 − 20)²)

d = √(156² + (−65)²)

d = √(156² + 65²)

156² = 156 × 156

156² = 24336

65² = 65 × 65

65² = 4225

24336 + 4225 = 28561

d = √(24336 + 4225)

d = √28561

d = 169

The horizontal distance is exactly 169 blocks.

Check the square root by multiplying 169 by itself.

169 × 169 = 28561

169² = 28561

√28561 = 169

The check matches the number under the radical.
